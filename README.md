# CV de Barre Beavogui

Portfolio réalisé avec React et Vite pour présenter mon parcours en génie électrique, mes expériences, ma formation et mes engagements.

Je suis actuellement en **5e année à Polytech Nantes**, où je prépare mon diplôme d’ingénieur en génie électrique. Mon **stage de chef de projet chez Schneider Electric, à partir de mars 2027, est confirmé et à venir**. Je ne recherche plus d’alternance.

## Démarrer en local

Avec Node.js 20 et npm :

```sh
npm ci
npm run dev
```

Ouvrir l’adresse indiquée dans le terminal, avec le chemin `/cv/`.

## Construire et prévisualiser

```sh
npm run build
npm run preview
```

La version de production est générée dans `dist/`.

## Déploiement

Le workflow GitHub Actions construit et publie le site sur GitHub Pages à chaque envoi sur la branche `main`. Il peut aussi être lancé manuellement. Vite utilise le chemin de base `/cv/`.

Site : [barre-beavogui.github.io/cv/](https://barre-beavogui.github.io/cv/).
